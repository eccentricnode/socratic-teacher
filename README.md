# Socratic Teacher

A reusable, question-led teaching skill for creating learning plans, resuming lessons, rigorous practice, and exploring contested ideas.

## Core

- `SKILL.md` — portable skill instructions and session routing.
- `Tools/Method.md` — Socratic teaching method and concept mastery criteria.
- `Tools/Setup.md` — learner-centered learning-plan and progress setup.
- `Tools/Adversarial.md` — rigorous interview mode.
- `Tools/Argue.md` — two-perspective debate and tribunal workflow.

Load `SKILL.md` with the adjacent `Tools/` guides available. The workflow can draft a journey from source material or a topic, then create plan/progress files only after the learner approves the plan and destination.
